AI for Creators

구글, Flow·Whisk·ImageFX 통합 — 크리에이터를 위한 AI 원스톱 워크스페이스 공개

Google Blog — 2026.05.20

Google I/O 2026에서 구글은 영상 생성 툴 Flow, 이미지 무드보드 Whisk, 텍스트-이미지 생성 ImageFX를 하나의 통합 워크스페이스로 합쳤습니다. 이제 크리에이터는 단일 인터페이스 안에서 이미지를 생성하고, 영상으로 변환하고, 편집까지 마칠 수 있습니다. Veo 3.1(싱크 오디오·대화 지원)과 Gemini Omni Flash가 플랫폼의 핵심 엔진으로 탑재됐으며, 유료 구독자는 즉시 이용 가능합니다. 또한 Flow TV라는 인앱 쇼케이스를 통해 다른 크리에이터들이 사용한 정확한 프롬프트와 기법을 열람할 수 있어, 실전 학습 속도가 빨라집니다.

At Google I/O 2026, Google merged Flow, Whisk, and ImageFX into a single unified AI workspace for creators. Users can now generate images, animate them into video, and edit everything inside one interface — powered by Veo 3.1, the only video model with synchronized native dialogue, and Gemini Omni Flash. Paying subscribers get immediate access. The platform also introduces Flow TV, an in-app showcase where creators can browse the exact prompts and techniques behind published clips — accelerating real-world skill building.

AI Tools / Pricing

GitHub Copilot, 오늘부터 토큰 기반 AI Credits 결제 전환 — 개발자·디자이너 비용 구조 바뀐다

GitHub Blog — 2026.06.01

2026년 6월 1일부터 모든 GitHub Copilot 플랜이 사용량 기반 AI Credits 결제로 전환됩니다. 1 AI Credit = $0.01이며, Copilot Pro+($39/월)에는 $39 상당의 크레딧이 기본 포함됩니다. 코드 자동완성(인라인)과 Next Edit Suggestions는 크레딧 소비 없이 무제한 무료로 유지되지만, 챗·에이전트 기능 등 고급 AI 기능은 모델별 토큰 요금에 따라 차감됩니다. 월정액 사용자는 오늘 자동 전환되며, 연간 플랜 사용자는 갱신 시점에 적용됩니다.

Starting today, June 1, 2026, all GitHub Copilot plans shift from flat-rate premium requests to usage-based AI Credits, priced at $0.01 per credit. Inline autocomplete and Next Edit Suggestions remain unlimited and free, while advanced features — chat, agentic workflows — consume credits based on each model's token rate. Copilot Pro+ at $39/month includes $39 in monthly AI Credits. Monthly plan users are auto-migrated today; annual plan holders migrate at renewal.

AI Industry / Security

Anthropic 미공개 모델 Claude Mythos, 오픈소스 소프트웨어에서 취약점 2만 3천 개 발견

Anthropic — 2026.05.26

Anthropic은 미공개 대형 언어 모델 Claude Mythos Preview를 활용해 1,000개 이상의 오픈소스 프로젝트를 스캔한 Project Glasswing의 초기 성과를 발표했습니다. Mythos는 총 23,019개의 이슈를 식별했고, 그 중 6,202개가 고위험·치명적 취약점으로 분류됐습니다. 검증된 사례의 90% 이상이 실제 취약점으로 확인됐으며, 수십억 기기에 탑재된 wolfSSL 암호화 라이브러리에서 은행·이메일 사이트를 사칭할 수 있는 인증서 위조 취약점도 발견됐습니다. AWS, Apple, Google, Microsoft 등이 파트너로 참여 중입니다.

Anthropic released initial results from Project Glasswing, which uses its unreleased Claude Mythos Preview model to scan critical open-source software. Scanning over 1,000 projects, Mythos flagged 23,019 issues — with 6,202 classified as high- or critical-severity. Over 90% of validated findings were confirmed as true positives. A standout discovery: a vulnerability in wolfSSL, a cryptography library on billions of devices, enabling an attacker to forge certificates and impersonate bank or email websites. Partners include AWS, Apple, Cisco, Google, Microsoft, and NVIDIA.

signal
구글의 Flow 통합과 GitHub Copilot의 AI Credits 전환이 같은 날 가시화된 것은 우연이 아닙니다. AI 툴은 이제 '있으면 좋은 기능'이 아니라 워크플로우의 중심 인프라가 됐고, 그에 따라 사용자에게 요구되는 리터러시도 달라지고 있습니다 — 어떤 기능이 크레딧을 소비하는지, 어떤 모델이 내 작업에 최적인지를 알아야 비용을 제어할 수 있습니다. 한편 Anthropic Project Glasswing은 또 다른 시사점을 줍니다: 크리에이터 툴을 지탱하는 오픈소스 생태계 자체의 보안을 AI가 책임지는 시대가 됐다는 것. 세 흐름의 공통점은 하나, AI는 이미 조력자가 아니라 인프라입니다.
