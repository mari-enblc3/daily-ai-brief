AI for Creators / Designers

Microsoft MAI-Image-2.5, 이미지 편집 기능 추가 — PowerPoint Copilot 당일 탑재

ChatForest, Jun 3 2026

Microsoft가 Build 2026에서 MAI-Image-2.5를 공개했다. 이전 버전(MAI-Image-2.0)과 달리 이번에는 이미지 편집 기능이 추가됐다—기존 이미지를 업로드하고 수정 지시를 입력하면 배경 교체, 스타일 변환, 요소 수정이 가능하다. 텍스트 렌더링 품질도 대폭 개선돼 브랜드 에셋이나 프레젠테이션 슬라이드 제작에 실질적인 업그레이드다. Arena 벤치마크에서 OpenAI·Google 다음으로 3위(1,254점)를 기록했으며, Build 당일부터 PowerPoint Copilot에 탑재됐다. 이미지 생성+편집을 Azure 단일 워크플로에서 처리할 수 있어 Microsoft 생태계 내 크리에이터에게 직접적인 혜택이 기대된다.

Microsoft unveiled MAI-Image-2.5 at Build 2026, marking a significant shift for the MAI-Image line: image editing is now supported. Users can submit an existing image alongside a text prompt to swap backgrounds, change styles, or modify specific elements — bringing it into the same capability class as OpenAI's gpt-image-2 and Google's Imagen Edit. Text rendering in generated images has also improved substantially, a practical gain for branded asset creation and presentation workflows. The model debuted at #3 on the Arena leaderboard with a score of 1,254 — behind only OpenAI and Google. It went live in PowerPoint Copilot on Build day, with OneDrive integration coming soon.

Anthropic, Claude Agent SDK 과금 6월 15일 분리 — 구버전 모델 2종 Deprecated

ChatForest, Jun 3 2026

Anthropic이 6월 15일부터 Claude API 과금 구조를 두 개의 독립된 풀로 분리한다. 기존에는 하나의 사용량 풀로 통합됐지만, 앞으로는 인터랙티브 사용(챗 인터페이스 등)과 Agent SDK 사용이 각각 별도로 집계된다. 동시에 두 모델이 deprecated된다: claude-sonnet-4-20250514와 claude-opus-4-20250514. Opus 4.7 이상 모델에서는 temperature·top_p 파라미터 지원도 종료된다. AI 툴을 API로 직접 연동해 사용하는 크리에이터나 스튜디오라면 6월 15일 이전에 사용 중인 모델 버전과 파라미터 설정을 반드시 점검해야 한다.

Anthropic is splitting Claude API billing into two separate usage pools starting June 15: one for interactive usage (chat interfaces, Claude.ai) and one for Agent SDK usage (automated pipelines, background agents). Previously, all API consumption counted against a single shared limit. Alongside the billing change, two models are being retired: claude-sonnet-4-20250514 and claude-opus-4-20250514. Additionally, temperature and top_p parameters will no longer be supported on Opus 4.7 and later models. For creators, studios, or teams running automated content workflows via Claude's API, this is a breaking change that requires action before the deadline.

AI Startup / VC / Industry

DeepSeek, 역대 첫 외부 투자 74억 달러 — Tencent·CATL 주도, 기업가치 최대 590억 달러

CNBC / Bloomberg, Jun 3 2026

중국 AI 스타트업 DeepSeek이 사상 첫 외부 투자로 약 74억 달러(50억 위안 상당)를 유치할 예정이다. Bloomberg와 Reuters에 따르면 Tencent·CATL·DeepSeek 창업자 량원펑이 직접 200억 위안을 투자하며, 중국 국가 AI 산업 투자 펀드도 참여한다. 투자 후 기업가치는 3,500~4,000억 위안($520~590억)으로 추정된다. 중국 최대 스타트업 투자 중 하나로 평가받는 이번 딜은 DeepSeek이 V3·R1 모델로 실리콘밸리를 놀라게 한 이후, 본격 수익화 단계로 넘어가는 첫 신호로 해석된다.

DeepSeek, the Chinese AI startup that stunned Silicon Valley in early 2025 with its V3 and R1 models, is closing its first-ever outside funding round at approximately $7.4 billion. According to Bloomberg and Reuters, term sheets are being signed this week, with Tencent and CATL as the two largest investors. DeepSeek's founder Liang Wenfeng is personally committing 20 billion yuan. China's National AI Industry Investment Fund is also participating, signaling strong state backing. The post-money valuation is expected to reach $52–59 billion. For the global AI industry, the deal marks China's AI sector entering a serious commercialization phase — and validates DeepSeek's low-cost, high-performance model approach at the capital-markets level.
