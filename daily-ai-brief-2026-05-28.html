AI for Creators

ChatGPT 음성 모드, 14개월 된 구형 모델로 조용히 운용 중 — 개발자 커뮤니티 강한 반발

출처: simonwillison.net  /  buildfastwithai.com

ChatGPT 음성 모드가 2024년 4월을 지식 마감일로 하는 GPT-4o 기반 구형 모델로 실행 중이라는 사실이 밝혀지며 개발자 커뮤니티에서 거센 비판이 일고 있습니다. 텍스트 인터페이스는 최신 GPT-5.5 Instant를 사용하는 반면, 음성 모드는 지난 1년간의 AI 발전이 모두 빠진 모델을 사용 중입니다. 이 사실은 개발자 Andrej Karpathy의 관찰을 Simon Willison이 공유하며 알려졌으며, OpenAI는 유료 구독자($200/월)에게 이를 명확히 고지하지 않았습니다. 구글 Gemini Live는 최신 Gemini 3.5 Flash를 음성 모드에 적용하고 있어 직접적인 비교 대상이 되고 있습니다.

Developer backlash erupted after Andrej Karpathy and Simon Willison revealed that ChatGPT's voice mode runs on a GPT-4o era model with an April 2024 knowledge cutoff — while the text interface uses the far newer GPT-5.5 Instant. This creates a 13-month capability gap for ChatGPT Pro users paying $200/month, with no prominent disclosure from OpenAI. The controversy highlights the technical constraint that real-time voice requires low-latency inference that frontier models cannot yet deliver cost-effectively. Google's Gemini Live, which uses the latest Gemini 3.5 Flash, is now the direct competitor comparison users are making.

Claude Code v2.1.152 업데이트 — 사용량 카테고리별 분석 대폭 강화, PowerShell 보안 취약점 패치

출처: releasebot.io  /  claudefa.st

Anthropic이 Claude Code v2.1.152(5월 27일 확인)를 배포하며 /usage 명령에서 스킬·서브에이전트·플러그인·MCP 서버별로 사용량을 상세히 확인할 수 있게 했습니다. 이제 어떤 구성 요소가 사용량을 가장 많이 소비하는지 정확히 파악할 수 있습니다. 또한 GitHub Flavored Markdown의 체크박스 목록 렌더링 지원, 키보드 탐색 가능한 diff 뷰어도 추가됐습니다. 주목할 점은 보안 패치: PowerShell 내장 cd 함수(cd.., cd\, cd~)가 권한 시스템을 우회해 워크스페이스 외부로 이동할 수 있던 취약점이 수정됐습니다. Windows 환경 사용자는 즉시 업데이트가 필요합니다.

Anthropic shipped Claude Code v2.1.152 (confirmed May 27) with a major upgrade to the /usage command, now showing per-category breakdowns across skills, subagents, plugins, and MCP servers — so developers can see exactly which components are consuming their capacity. New features also include keyboard-navigable diff scrolling and GitHub Flavored Markdown task list checkbox rendering. Critically, a security advisory accompanies v2.1.149+: a permission bypass in PowerShell's built-in cd functions allowed workspace directory traversal outside permitted boundaries without triggering Claude Code's permission system. Windows users must update immediately via claude update or winget upgrade Anthropic.ClaudeCode.

ElevenLabs, 시리즈 D $5억 달러 조달 — 음성 AI 기업 가치 110억 달러로 도약

출처: aifundingtracker.com  /  crescendo.ai

음성 AI 플랫폼 ElevenLabs가 시리즈 D 라운드에서 5억 달러를 조달하며 기업 가치 110억 달러를 기록했습니다. 팟캐스트·오디오북·인터랙티브 음성 앱 등 오디오 기반 제품을 구축하는 개발자와 기업들의 핵심 인프라 레이어로 자리잡고 있습니다. 크리에이터와 미디어 기업들이 음성 AI를 콘텐츠 제작 파이프라인에 통합하는 추세가 빠르게 확산되고 있으며, 이번 투자는 음성 AI가 텍스트·이미지 생성에 이어 크리에이터 경제의 다음 핵심 인프라가 되고 있음을 보여줍니다.

Voice AI platform ElevenLabs raised $500 million in its Series D round, valuing the company at $11 billion. The platform has emerged as the go-to infrastructure layer for developers and enterprises building audio-driven products — from podcasts and audiobooks to interactive voice applications. The round reflects accelerating creator adoption as media companies integrate voice AI throughout their content production pipelines. The investment signals that voice AI is becoming the next essential infrastructure layer in the creator economy, following text generation and image synthesis.

오늘의 세 뉴스는 AI 업계의 같은 단층선을 서로 다른 각도에서 보여줍니다. ChatGPT 음성 모드 논란은 AI가 '인프라'로 자리잡을수록 무엇을 실제로 제공하는지에 대한 투명성 요구가 커진다는 것을 드러냅니다. 월 $200을 내는 사용자에게 14개월 된 모델을 조용히 사용하게 하는 것은, AI가 더 이상 신기한 도구가 아닌 '당연한 인프라'가 됐을 때 통하지 않는 방식입니다. Claude Code v2.1.152의 사용량 투명성은 그 반대의 방향입니다 — 어떤 구성 요소가 얼마나 소비되는지 정확히 보여주는 것. ElevenLabs의 $5억 조달은 음성 AI가 텍스트·이미지에 이어 크리에이터 경제의 다음 필수 인프라가 됐음을 자본이 공인한 순간입니다. 크리에이터·디자이너에게 시사점은 명확합니다: 도구가 인프라가 되는 순간, '실제로 무엇을 받고 있는가'를 스스로 검증하는 능력이 핵심 역량이 된다.
